# Interactive 3D Wireframe

This standalone Web64 project renders a perspective wireframe cube with the optimized Bitmap Drawing Runtime.

- `W` / `S` rotate around the X axis (pitch).
- `A` / `D` rotate around the Y axis (yaw).
- The included `rotation-matrices.h` is generated by Web64's Matrix generator from the `rotation3d-x` and `rotation3d-y` presets.
- Each table contains 32 cyclic row-major Q8.8 matrices using column-vector math.
- Eight cube vertices are transformed and projected into the 320x200 hires bitmap.
- The 12 edges use `web64_bitmap_line_fast()`. XOR drawing erases the previous wireframe exactly before drawing the updated orientation.
- The project owns its bitmap, palette, transformed coordinates, and rotation indices; the runtime adds no scene graph or hidden object state.

Open `bitmap-wireframe-3d.web64proj` in Web64 IDE and run it. Keep keyboard focus on the emulator while using WASD.
